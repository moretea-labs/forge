## Classification and ownership rules

`source` means a repository implementation defect or invariant. `runtime/deployment` means immutable Runtime activation, live provider/MCP behavior, or delivery state. `external` means infrastructure outside Forge source authority. `persistent` means an intentionally non-terminal scheduled workflow. `history` means retained proof for a defect already closed on current source/runtime.

A row is **closed** only when current-main ancestry and/or current Runtime evidence proves the closure. A terminal Work record alone is not sufficient. Every **open P0/P1** below has exactly one current owner: one exact Work, one Plan step, or one explicit blocker. Intentional persistent workflows are not treated as defects merely because they remain non-terminal.

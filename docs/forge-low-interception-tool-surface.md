# Forge Tool Surface

Forge exposes a compact stable facade for ordinary work and keeps diagnostic or compatibility internals outside the default user path. Capability discovery describes bundled providers without dynamically changing the MCP schema. Access mode changes authorization behavior, not tool identity.

See [Repository access modes](architecture/current/repository-access-modes.md) and [Thin Harness governance](architecture/current/thin-harness-governance-policy.md).

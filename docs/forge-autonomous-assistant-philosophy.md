# Forge Supervised Automation Philosophy

Forge is a local-first execution kernel, not an unbounded autonomous agent. External controllers decide semantic goals; Forge persists Work, enforces policy and resource ownership, executes bounded operations, and returns evidence. Every loop has a finite budget, stop condition, and explicit external-effect boundary.

See [Dispatch and Agent Strategy](architecture/current/dispatch-and-agent-strategy.md) and [Governance](architecture/current/governance.md).

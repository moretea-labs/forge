# Forge iOS Development Capability

Forge provides optional iOS simulator, physical-device, build, inspection, and App Store related operations through first-party adapters. Operations remain repository-scoped, permission-gated, timeout-bounded, and evidence-producing. Device or account approval remains a human interaction boundary.

See [Plugin management](forge-plugin-management.md), [Human Interaction Plane](architecture/CURRENT.md), and the [iOS physical-device migration baseline](architecture/decisions/20260904-ios-device-migration-baseline.md).

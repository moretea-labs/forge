# Forge

Forge est un assistant d’action local-first pour le développement logiciel. Il relie ChatGPT à l’état réel de vos dépôts, commandes et vérifications locales.

La documentation complète et maintenue se trouve dans [README.md](README.md). Consultez aussi le [Wiki](docs/wiki/Home.md), l’[architecture](docs/wiki/Architecture.md) et la [carte d’implémentation](docs/wiki/Implementation.md).

La version candidate actuelle est `1.5.0-rc.1`. Les versions candidates de `@moretea-labs/forge` utilisent le canal npm `next` ; les versions stables utilisent `latest`.

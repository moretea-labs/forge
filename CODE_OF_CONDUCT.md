# Code of Conduct

## Our commitment

We are committed to a respectful, harassment-free project for contributors and users regardless of background, identity, experience level, or point of view.

## Expected behavior

- Be respectful, specific, and constructive.
- Critique code and decisions, not people.
- Assume good intent while still requiring evidence for technical claims.
- Respect privacy, security boundaries, and confidential information.
- Accept maintainer decisions about scope, safety, and release readiness.

## Unacceptable behavior

Harassment, threats, discriminatory language, deliberate disruption, doxxing, publishing private information, or using project channels to pressure others is not acceptable.

## Enforcement

Report conduct concerns privately through the repository maintainers. Do not publish sensitive personal details in an issue. Maintainers may edit or remove content, close discussions, restrict participation, or take other proportionate action to protect the community.

This policy applies in repository spaces and when someone is representing the project in public.

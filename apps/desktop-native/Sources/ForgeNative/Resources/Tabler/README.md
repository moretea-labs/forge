# Tabler Icons (Forge subset)

Source package: `@tabler/icons` 3.52.0
Upstream: https://github.com/tabler/tabler-icons
License: MIT; see `LICENSE`.

These are unmodified official outline SVG assets from one icon family. Each uses the upstream 24×24 grid and 2px outline stroke. Forge loads them as template images so the same source asset follows the current foreground color. Do not hand-draw replacement paths or mix unrelated icon families; add new assets only from the same pinned package release.
